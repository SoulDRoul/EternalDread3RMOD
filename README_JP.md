# ED3R Mod — Eternal Dread 3 機能拡張

**『Eternal Dread 3』用の大型機能拡張Modです。**
デフォルト設定は「強化爽快プレイ」寄りですが、各項目は調整可能で、バニラ（原作）に戻すこともできます。

> ⚠️ **メンテナンス状況**：本Modはリリース後、基本的にメンテナンスを行いません。問題が発生した場合は、ご自身でソースコードを確認するか、Issuesをご確認ください（作者がすぐに返信できない場合があります）。

---

## ✨ 主な機能

### 操作と利便性
* ダッシュのスタミナ消費はデフォルトで25%、任意の方向にダッシュ可能。
* 採集および回復アイテムの使用は中断可能で、効果は即座に適用されます。
* 拾得範囲が拡大し、インベントリと装備スロットが自動的に1ページ拡張されます。
* インベントリを開くと自動的にソートされ、ソートルールを切り替え可能です。

### 戦闘とスキル
* バックスタブ、回り込み、スタン、凍結、ダウン、ガードカウンターが戦局に影響します。
* 毒と燃焼は致死性があり、燃焼は延焼し、ローリングで一度に消火できます。
* マルチクリティカル、レベル差補正、凍結貫通などのメカニクスを選択可能。
* スキルツリーの前提条件が緩和され、スキルポイントのリセット、パッシブスロットの拡張が可能です。

### 敵とAI
* コーン状の視界、壁の遮蔽、騒音への警戒、発見プロンプト。
* 敵のレベル追従上限は難易度によって設定され、完全にプレイヤーに追従することはなくなります。
* 夜間に生成される敵は、難易度に応じてランダムな修飾子とレベルボーナスを獲得します。

### キルストリークと生態系
* 連続キルは D / C / B / A / S / SS / SSS で評価されます。
* エリアのモンスター密度はキルによって減少し、時間とともに回復します。
* クエストエリアは生態系フィルターの対象外となり、ストーリーモンスターが正常にスポーンします。

### UIとミニマップ
* 脅威リングがロックオン中および攻撃中の敵を指示します。
* ミニマップに敵、味方、資源、宝箱、スキルポイントを表示します。
* Ctrlキーを押し続けると会話を高速スキップ、ポップアップのクイック確認が可能です。

### パーマデス（任意）
* キャラクター作成画面でチェック可能、死亡するとセーブデータが削除されます。
* システムを熟知した後に真のハードコア体験を求めるプレイヤー向けです。

## 📥 インストール方法

1. BepInEx x64 をインストールし、ゲームのルートディレクトリに解凍して、まず一度ゲームを起動します。
2. 本リポジトリ右側の **Releases** タブをクリックし、最新のインストールパッケージ（`.zip`）をダウンロードして解凍し、`BepInEx` フォルダをゲームのルートディレクトリに上書きしてください。
3. ゲームを再起動し、キルストリークUIなどのUI要素が表示されればインストール成功です。

*ヒント：ゲームパスは英字のみを推奨します。中国語や特殊記号は避けてください。*

## ⚙️ 設定とローカライズ

**設定ファイルの場所：**
`BepInEx\config\com.SoulDRoul.EternalDread3Rmod.cfg`

デフォルト設定が推奨設定です。そのまま遊べます。バニラ（原作）に戻す、ステルス、キルストリーク爽快プレイ、ハードコアチャレンジにしたい場合、完全マニュアル第11章に対応する調整方針があります。設定変更はゲーム再起動後に有効になります。

**ローカライズ対応：**
中国語、英語、日本語を内蔵。デフォルトは中国語。`BepInEx\config\ED3R_Language.txt` で切り替え、1行変更してゲームを再起動するだけです。翻訳ファイルがない場合は自動的に中国語にフォールバックし、エラーは出ません。

> 📖 **完全マニュアルについて**：現在中国語のみの提供です。精力の関係上、完全な英語・日本語翻訳は提供していません。コミュニティによる翻訳のPull Requestを歓迎します！
