# ED3R Mod — 永恒恐惧3 功能扩展

**一个为《永恒恐惧3》制作的大型功能扩展 Mod。**
默认配置偏“增强爽游”，但每一条都可以调，也可以还原原版。

> ⚠️ **维护状态说明**：本 Mod 发布后基本不再维护。如遇问题，请自行研究源码或查阅 Issues（作者可能无法及时回复）。

---

## ✨ 主要功能

### 操作与便利
* 冲刺体力消耗默认 25%，任意方向可冲刺。
* 采集和恢复类物品使用可被打断，效果立即生效。
* 拾取范围扩大，物品栏和装备栏自动扩展一页。
* 打开物品栏自动排序，排序规则可切换。

### 战斗与技能
* 背刺、绕后、眩晕、冰冻、倒地、格挡反击都会影响战局。
* 中毒和燃烧可致死，燃烧会蔓延，翻滚可一次灭火。
* 多重暴击、等级差补正、冰冻穿透等机制可选。
* 技能组前置放宽，技能点可刷新，被动槽位可扩展。

### 敌人与 AI
* 锥形视野、墙体遮挡、噪音警觉、发现提示。
* 敌人等级跟随玩家的上限按难度设置，不再完全跟随。
* 夜晚生成的敌人按难度概率获得随机词条和等级加成。

### 连杀与生态
* 连续击杀按 D / C / B / A / S / SS / SSS 评级。
* 区域怪物密度会因杀戮下降，随时间恢复。
* 任务区域豁免生态过滤，保证剧情怪正常刷新。

### 界面与小地图
* 威胁环指示锁定和攻击中的敌人。
* 小地图显示敌人、友军、资源、宝箱、技能点。
* 按住 Ctrl 快速跳过对话，弹窗快捷确认。

### 永久死亡（可选）
* 创角界面可勾选永久死亡模式，死亡即删档。
* 给熟悉系统之后想要真正硬核体验的玩家准备。

## 🔧 前置要求

* 必须安装 **BepInEx x64**（推荐版本：`BepInEx_win_x64_5.4.23.5`）。
* 针对《永恒恐惧3》`v1.0` 版本开发。
* BepInEx 官方下载地址：[https://github.com/BepInEx/BepInEx/releases](https://github.com/BepInEx/BepInEx/releases)

---

## 📥 安装方法

1. 安装 BepInEx x64 版本，解压到游戏根目录，先运行一次游戏。
2. 点击本仓库右侧的 **Releases** 标签，下载最新的安装包（`.zip`），解压后将 `BepInEx` 文件夹覆盖到游戏根目录即可。
3. 重启游戏，出现连杀 UI 等界面元素即安装成功。

*提示：游戏路径建议纯英文，避免中文或特殊符号。*

---

## ⚙️ 配置与本地化

**配置文件位置：**
`BepInEx\config\com.SoulDRoul.EternalDread3Rmod.cfg`

默认配置就是推荐配置，直接玩即可。想还原原版、潜行、连杀爽游或硬核挑战，完整手册第十一章有对应调整方向。改完配置需要重启游戏才生效。

**本地化支持：**
内置中文、英文、日文，默认中文。通过 `BepInEx\config\ED3R_Language.txt` 切换，改一行、重启游戏即可。翻译文件缺失时自动回退中文，不会报错。

> 📖 **关于完整手册**：目前只提供中文版。由于精力有限，暂不提供完整的英日文翻译。非常欢迎社区提交手册的英文/日文翻译 PR！
